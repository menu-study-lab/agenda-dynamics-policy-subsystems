# 网页演示使用与修改说明

## 打开方式

双击 `index.html`，使用 Chrome 或 Edge 打开。

快捷键：

- `←` / `→`：上一页、下一页。
- `N`：显示或隐藏讲者备注。
- `O`：打开页面总览。
- `F`：进入或退出全屏。
- `Esc`：关闭备注、总览或全屏。

第12页下方的年份滑杆可以拖动。点击“播放”会自动展示1965—1979年的场域进入顺序。

第1页的两位作者都可以点击，打开作者简介；按 `Esc` 关闭。

第17页右侧的后续研究可以点击。点击后，左侧对应的原文机制会高亮。

各页正式标题统一采用两行结构：英文标题在前，中文标题在后。关键机制页会在进入时按顺序展开；第3页时间线、第8页反馈链、第9页证据流、第12页场域序列和第14页公众意见条形图都保留了逐层出现的动效。

## 修改文字

所有页面文字和讲者备注都保存在 `content.js`。建议用支持 UTF-8 的文本编辑器打开，直接修改对应页面中的中文、英文或备注。

页面数组位于：

```text
window.DECK_DATA.slides
```

时间轴数据位于：

```text
window.DECK_DATA.timelineEvents
```

修改后保存并刷新浏览器即可。

## 文件结构

- `index.html`：页面框架和控制按钮。
- `content.js`：全部文案、引文、讲者备注和时间轴数据。
- `styles.css`：颜色、字体、布局和动画。
- `deck.js`：翻页、备注、总览、时间轴及研究配对交互。
- `assets/`：作者照片和论文原图。

静态版备份位于上一级目录的 `政策为何会突然转向_网页版_18页_静态备份.pdf`，用于网页或动画无法播放时继续展示。

## 版式维护

- 正文以 `24px` 作为约18pt的基准。
- 来源、页码、图号和参考文献可以使用较小字号。
- 修改长句后应重新检查中文断行和图文重叠。
- 保持每页一个主要视觉中心，避免继续增加小型说明框。
